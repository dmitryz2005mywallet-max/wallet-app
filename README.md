# Мой кошелёк

Личные финансы на телефоне: доходы и расходы, категории с любой вложенностью (иконка и цвет настраиваются), лимит на месяц, постоянные операции, разбивка «Куда уходят деньги / Откуда деньги», светлая и тёмная тема.

Основная валюта — злотый (zł). Рядом с суммами можно показывать пересчёт в EUR, USD или UAH по курсу из открытых источников (Нацбанк Польши, ПриватБанк, НБУ и др. — берётся первый, что ответил); курс можно ввести и вручную.

Приложение — один файл `index.html` без сборки. По умолчанию все данные хранятся в браузере устройства (localStorage). Если подключить Firebase (см. ниже), они ещё и синхронизируются между устройствами через ваш Google-аккаунт.

## Открыть

https://<ваш-логин>.github.io/<имя-репозитория>/

Это PWA: приложение ставится на главный экран, открывается без адресной строки и работает без интернета (файлы кэширует `sw.js`). На iPhone: Safari → «Поделиться» → «На экран «Домой»». На Android и в Chrome на компьютере: меню браузера → «Установить приложение» или пункт «Установить приложение» в меню самого приложения.

## Данные

- Без облака данные есть только на том устройстве и в том браузере, где вы вводили операции.
- Резервная копия: меню ⋯ → «Сохранить копию в файл» (скачивается файл), восстановление: «Восстановить из копии». Делайте копию перед очисткой данных браузера.

## Облако (Firebase): синхронизация между устройствами

Бесплатного тарифа Spark хватает с большим запасом. Один раз:

1. https://console.firebase.google.com → **Add project** (имя любое, Google Analytics не нужен).
2. **Build → Authentication → Get started → Sign-in method → Google → Enable**, выберите почту поддержки, сохраните.
3. **Authentication → Settings → Authorized domains → Add domain**: `<ваш-логин>.github.io` (например `antonnikonov1.github.io`).
4. **Build → Firestore Database → Create database**, регион `eur3` (Europe) или `europe-central2` (Warsaw), режим Production.
5. Вкладка **Rules** → вставьте содержимое файла `firestore.rules` → **Publish**.
6. **Project settings (шестерёнка) → General → Your apps → Web (`</>`)** → зарегистрируйте приложение и скопируйте объект `firebaseConfig`.
7. Подставьте `apiKey`, `authDomain`, `projectId`, `appId` в файл `firebase-config.js` и запушьте в `main`.

После этого при открытии приложения появляется экран входа через Google: без входа пользоваться приложением нельзя. На втором устройстве войдите в тот же аккаунт, данные подтянутся сами. Тот, кто уже входил, может работать и без интернета. При выходе (меню ⋯ → «Облако и синхронизация» → «Выйти») данные с устройства удаляются, в облаке они остаются; если не отправлены последние изменения, выйти не дадут.

Пока в `firebase-config.js` стоят заглушки `PASTE_…`, экрана входа нет и приложение работает локально.

Как работает: приложение всегда читает и пишет локально (работает без интернета), а при наличии сети отправляет изменения в Firestore (документ `users/<ваш uid>`) и забирает чужие. Если правки сделаны на двух устройствах сразу, они объединяются: добавленное сохраняется с обеих сторон, удалённое на одном устройстве удаляется на другом, при правке одной и той же операции побеждает более поздняя. Лимит облачного документа — около 1 МБ (порядка 5–6 тысяч операций).

## Обновление

Заменить `index.html` и запушить в `main`. GitHub Pages обновится за минуту.
